## 2. Privacy Policy & Zero Data Collection (GDPR & CCPA Compliant)
CovaMac is architected with a strict **Local-First, Zero-Telemetry** privacy model:

1. **Zero Personal Data Collection**: CovaMac does not collect, record, log, store, or transmit any user names, email addresses, IP addresses, hardware identifiers, files, or location data.
2. **100% On-Device Processing**: All battery telemetry, CPU/RAM diagnostics, duplicate file scanning, uninstaller residual indexing, and developer cache analysis occur strictly on the user's local Mac using sandboxed macOS APIs.
3. **Zero Third-Party Trackers**: CovaMac contains zero analytics SDKs (e.g., No Google Analytics, No Mixpanel, No Facebook Pixel, No crash telemetry phone-homes).
4. **Local Network Diagnostics**: Network latency and ping telemetry are performed directly via local command-line utilities (`/sbin/ping`) to standard public DNS resolvers (`1.1.1.1`, `8.8.8.8`). No network traffic is intercepted, inspected, or forwarded.
